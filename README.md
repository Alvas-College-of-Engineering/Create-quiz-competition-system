# Quiz Competition System

A Simple Java Quiz Competition System with Frontend using HTML, CSS, and JavaScript.

## Features

- Multiple Choice Questions
- Score Calculation
- Final Result Display
- Participant Details
- Java OOP Concepts
- Simple Frontend UI

## Technologies Used

- Java
- HTML
- CSS
- JavaScript

## Run Frontend

Open `index.html`

## Run Java Program

Compile:

```bash
javac QuizCompetition.java
